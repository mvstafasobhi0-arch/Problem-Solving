# Even & Odd Checker

A simple JavaScript task that checks whether a number is even or odd.

## Problem Description

Determine whether a given number is even or odd.

- **Even:** The number is divisible by 2 with no remainder.
- **Odd:** The number leaves a remainder when divided by 2.

## Example

| Input | Output |
|---:|---|
| 4 | Even |
| 7 | Odd |
| 0 | Even |
| -3 | Odd |

## Concepts Practiced

- JavaScript conditionals
- The modulo operator (`%`)
- Working with user input
- Displaying results in the UI
